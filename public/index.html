VibeVault recovery

This page is used as a fallback for VibeVault’s secure email sign-in links.

To finish recovery, open the email link on the same Android device where you requested it. The link should open VibeVault so you can set your new vault PIN.

If you reached this page instead of the app, return to VibeVault and check that the app is installed and its Firebase App Links are verified.
